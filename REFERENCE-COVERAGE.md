# Jeem reference coverage

This matrix compares the interpreter with the sources that can currently be recovered. The 2007 study is a historical summary. The 15-lesson course is a later, author-attributed edited publication. Neither source is a current normative specification, and some original pages are no longer fetchable.

| Source area | Implemented | Remaining gap or explicit profile rule |
| --- | --- | --- |
| Lesson 1: overview and original environment | Source programs run through the Rust library and CLI. | The Al-Khwarizmi editor, compiler, debugger, and full Windows environment are not recreated. |
| Lesson 2: vocabulary | Arabic keywords, the recovered reserved-word table, identifiers, Arabic digits, source comments, and documented spaced names with numeric suffixes (such as `سر 0` and `جيب 90`) are recognized for implemented forms. | Exact Unicode normalization and all lexical edge cases are not specified by accessible sources. |
| Lesson 3: primitive and compound types | `صحيح`, `صغير`, `حقيقي`, `منطقي`, `حرف`, `مؤشر`, and `ملف` declarations are recognized; scalar values, named records, array aliases, and record arrays have runtime representations. Record bodies accept `مركب`, `سجل`, `كيان`, or `وحدة`. | `صغير` has no verified width/range. Pointer allocation and dereference are not specified by the available sources. |
| Lesson 4: variables, constants, assignment | Source-order variable visibility, compile-time expressions over literals and earlier constants, fixed array sizes from integer constant expressions, optional `أجعل`, numeric promotion to real, and logical comparisons are supported. | Some original numeric bounds and all mixed-type edge cases are unspecified. |
| Lesson 5: input and output | Scalar numeric/character input, multi-target `أقرأ`, character-array text input, scalar/text output, and `سطر`. | The host API requests input once per target. The original environment's exact prompt, parsing, and multi-value entry behavior is not established. Logical and compound values are not directly printed, following the course description. |
| Lesson 6: conditionals | `إذا`, optional `وإلا`, boolean conditions, comparison operators, and logical operations. | Block delimiters are reconstructed from examples; alternative one-line forms are not claimed. |
| Lesson 7: loops | Counted, while, repeat-until, and range loops, including optional `بخطوة`. `أنتهي` halts execution. | Range endpoints are treated as inclusive, and counted loops with nonpositive values run zero times. Complete overflow, step, and loop-variable rules are not stated in the sources. |
| Lesson 8: compiler directives | `بدل` and `البديل` substitutions, escaped quotes, recursive `أدرج` file inclusion, source-order substitution, and library lookup beside the main source then in `common libs` beside the executable are supported. The five libraries in Lesson 15 are supplied as built-in profiles. | Custom included-source diagnostics report expanded-source line numbers; original file names and include-stack locations are not retained. The CLI's common-library directory is relative to its executable. |
| Lesson 9: arrays | Fixed-size one- and multi-dimensional arrays of scalar and record elements; indexed reads, writes, indexed record fields, and by-reference element arguments. One-dimensional character arrays support text input and a zero terminator. | The accessible course example supports one-based character indexing, which is applied to all arrays. Dynamic sizing, exact index-base rules for other array types, and array layout are not confirmed. |
| Lesson 10: records | Named types use `النوع Name: مركب`, `سجل`, `كيان`, or `وحدة` followed by `{ ... }`; typed fields, nested records, dotted field reads and writes, indexed record-field access, and value-copy assignment are implemented. `check(&program)` validates field paths and propagates field types through assignments, expressions, arguments, and returns. Record fields remain uninitialized until assigned; record and array containers are allocated lazily or at declaration. | The lesson does not define structural compatibility, default values, or pointer/reference semantics for records. |
| Lesson 11: algorithms and functions | Routine declarations, typed scalar and array parameters, local variables, arrays and compile-time constants, calls, scalar return values, recursion, mutable pass-by-reference arguments of matching types, copy-in `الثابت` parameters, temporary cells for rvalue arguments, and spaced numeric names such as `بي 1`. | The exercises confirm array arguments and the text-as-character-array rule but do not show a complete formal array declaration; this profile uses `صفيفة من <scalar type>` and derives shape from the actual. Writable actuals with compatible but different numeric types are passed through temporary cells without copy-back. Exact overload resolution and all call/scoping edge cases are not implemented. |
| Lesson 12: files | File variables support `أفتح ... للقراءة من ...`, `أفتح ... للكتابة في ...`, `أقرأ من ... : ...`, `أكتب في ... : ...`, and `أغلق ...`. File path resolution, reading, writing, and closing are delegated to `Host`. | Append mode, encoding, record boundaries, and automatic cleanup after runtime errors are not specified. The CLI host does not provide file access. |
| Lesson 13: geometric graphics | Point, chained line, circle, ellipse, rectangle, triangle, persistent stroke and fill colors, filled shapes, canvas fill, and labels parse into typed `DrawingCommand` values delivered to `Host::draw_command`; RGB channels use the lesson's 0–100 range. `حدس`/`حدع` use host drawing bounds. The old circle callback remains supported. | The host supplies the drawing surface and cursor state. Numeric precision, label-cursor behavior, and persistence are not settled by the recovered lessons. The CLI has no graphics service. |
| Lesson 14: recursion | Recursive algorithms and functions execute with a call-depth guard. | The limit is an interpreter safety policy, not a source-language rule. |
| Lesson 15: standard libraries | Math constants and `ظل`, `تظل`, `باقي`, and `تدوير`; `كلمة`, `أبجدي`, `طول_الكلمة`, `أنسخ_كلمة`, `أقارن_كلمتين`, and `عكس`; color aliases, palette loading and color selection; complex-number record construction, arithmetic, conjugation, magnitude, drawing, input, and output; and synonym substitutions. `نسخ_كلمة` is also accepted as a compatibility alias. `جب`/`تجب` use radians, matching the course example. | The remaining listed predefined functions (`عجب`, `عتجب`, `عظل`, `جديد`) have no recoverable signatures and remain unavailable. `حدس`/`حدع` are host-backed drawing bounds. The `صحيح(real)` truncation rule is an explicit policy because rounding behavior is not stated. The original `أبجدي` example uses encoding-specific character-code exclusions; this profile recognizes the Arabic Unicode letters in its documented ranges. |
